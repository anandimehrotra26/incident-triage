# Demo feedback

**Status: NOT YET COLLECTED.** Nothing below is real feedback. Do not submit this file as evidence until a real person has filled it in.

## How to collect it (10 minutes)

1. Run `make demo` (or `python -m triage.train && python demo/server.py 8000`) and share the screen / let the person use it.
2. Ask them to triage 5 reports of their own invention, including one vague one and one they think is urgent. They can press **yes / no** under each result; every press is logged to `demo/feedback_log.jsonl` (git-ignored; copy it into this repo as `demo/feedback_sample.jsonl` if they agree).
3. Ask the questions below and paste their answers verbatim.

## Questions

1. Did the route and priority match what you would have chosen? (n of 5)
2. Was there a case where it was confidently wrong? What was it?
3. Did "needs human review" feel helpful or annoying?
4. What would stop you trusting it for real incidents?
5. One thing to change.
